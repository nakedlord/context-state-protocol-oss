# Security

Please do not report sensitive issues through public examples or pull request
text.

## Data Safety

CSP repositories can contain durable project memory. Before publishing,
review for:

- local filesystem paths;
- private repository names;
- secrets and tokens;
- personal data;
- customer or business data;
- health or financial context;
- raw chat exports;
- source documents that were not intended for publication.

Use a clean public export with new git history instead of making a private CSP
working repository public.

## Reporting

Open a GitHub security advisory when available, or contact the repository owner
through the profile contact path.
