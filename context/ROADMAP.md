# CSP Roadmap

## Near Term

- Keep the public skeleton small and easy to copy.
- Improve `csp_status.py` for fast agent entry.
- Add more task packet examples.
- Add privacy scan guidance for public exports.

## Mid Term

- Add optional adapters for search and vector indexes.
- Add examples for multi-repository knowledge ingestion.
- Improve CI checks for projection drift and unsafe producer writes.

## Long Term

- Build agent UI affordances on top of CSP without making the UI the source of truth.
- Support multiple agents working against the same context repository with explicit role boundaries.
